# 릴리스 체크리스트

> 마지막 릴리스 태그 이후 **새로 구현된 기능 / 고친 버그**를 정리하고, 그중 손으로
> 직접 확인해야 하는 항목을 체크리스트로 관리하는 문서다. 자동 테스트(pytest)로
> 이미 고정된 것은 여기 올리지 않는다 — 여기 적는 건 **사람이 실제로 눌러 봐야
> 아는 것**만이다.
>
> **작업 단위(버그 하나 고침, 기능 하나 추가 등)가 끝나면 그 커밋 안에서 바로
> "다음 릴리스" 절을 갱신한다.** [CLAUDE.md](../CLAUDE.md) "릴리스 체크리스트 관리"
> 참고. 릴리스 태그를 달기 전에는 반드시 이 문서의 미확인 체크박스를 확인한다
> ([DEVELOPMENT.md §13](DEVELOPMENT.md)).

## 다음 릴리스 (기준: v0.2.1 이후, 미출시)

### 새로 구현된 기능

- 진단 정보에 재생 환경이 실린다: 브라우저 종류·버전, Main/Main10 코덱 판정과 하드웨어 디코딩 여부, 브라우저가 쓰는 GPU, 모든 GPU·드라이버 버전, 설치된 HEVC 확장. 풀영상이 재생되지 않으면 그 사실이 오류 기록에도 남는다.

### 고친 버그 / 개선

- 풀영상 화면이 오류 없이 검게 나오는 경우(`videoWidth 0`)에도 안내 문구가 뜬다(전에는 오류 이벤트가 있을 때만). V09.

### 실측 체크리스트 (릴리스 전에 전부 확인)

- [ ] HEVC 를 못 트는 깨끗한 PC(또는 HEVC 확장 없는 Windows)에서 풀영상을 열어 안내 문구가 뜨고, 옵션 → 정보·진단 → "진단 정보 보내기" 미리보기에 `browser`·`hevcProbe`·`hevcExtension` 이 실리는지(E2E 는 번들 Chromium 으로 흉내만 낸다).

> 화면에 뜨는가·문구·배지·메뉴·확인 창·단축키·주소/뒤로 가기·삭제/보관 흐름처럼 **누르면 아는 것은**
> `pytest e2e -m e2e`([DEVELOPMENT.md "화면 E2E"](DEVELOPMENT.md))와 pytest·프론트 테스트가 맡는다 —
> 어떤 시나리오가 어떤 옛 항목을 대신하는지는 [e2e-scenarios.md](e2e-scenarios.md). 여기에는 **실제 게임·스팀·큰 파일·사용자
> 실데이터·깨끗한 PC 가 있어야만 보이는 것**만 둔다([DEVELOPMENT.md §13](DEVELOPMENT.md) 기준 — H1~H4 + 해당 C 항목 + 이번 릴리스 고유 항목).

## 지난 릴리스

기록을 여기 쌓지 않는다. 릴리스가 나가면 위 절을 비운다 — 사용자용 변경 내용은 루트
[CHANGELOG.md](../CHANGELOG.md), 실측 경위는 그 릴리스 커밋(`git log v이전..v이번 -- docs/release-checklist.md`)에 있다.
