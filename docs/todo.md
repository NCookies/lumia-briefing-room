# TODO 입력함

> 사용자가 자유롭게 적는 입력 전용 파일이다. `/todo-sync` 세션이 이 파일을 읽고
> 문서(SPEC / plan*.md / README)에 반영한다. **코드는 건드리지 않는다.**
>
> 형식: `- [ ] 내용` 한 줄이 한 항목. 보충 설명은 들여쓴 하위 줄에 적는다.

## 당장 구현

- [ ] 볼륨 자동 저장 (코드 수정 후 다시 실행하면 소리 설정이 초기화되어 있음. 쿠키로 저장하던가 해야할 듯)
- [ ] 자동 삭제 기능 : 정리 기준을 체크 박스 같은거 써서 직관적으로 ui 변경하면 좋을 것 같음
- [ ] 브라우저 디버깅 환경 구축: 사용자가 직접 테스트하다 난 오류를 캡처·복사 없이 Claude Code 가 읽을 수 있게 + Claude 가 브라우저를 직접 띄워 디버깅할 수 있게
  - 로그 수집(기본): window.onerror / unhandledrejection / console.error 를 백엔드 엔드포인트로 전송해 서버 로그와 같은 파일에 기록. Claude 는 그 파일을 읽는다
  - 브라우저 자동 디버깅: 브라우저 MCP 를 연결해 Claude 가 직접 화면 확인·콘솔 로그 읽기·조작을 하게 한다 (Chrome DevTools MCP, Playwright MCP, Claude in Chrome 확장 중 이 프로젝트에 맞는 것을 문서에서 정하고 연결 방법을 README 에 적기)
  - 지금은 개발 중 "브라우저 디버깅은 못 했다"는 답이 나오는 상태 — MCP 연결이 그 원인을 해소하는 것이 목적

## 추후 구현

- [ ] 저장 버튼 윈도우 내장으로 변경하기 (지금은 웹에서 선택하는데 너무 불편하고 이질적임)
- [ ] 설치 및 배포 간편화
  - 사용자 환경에 별도로 프로그램이나 코덱 등을 설치하지 않아도 사용할 수 있도록 (배포 파일 내에 전부 포함)
  - 스팀 리플레이 파일 위치 자동으로 인식하거나 처음 실행했을 때 설정하도록 (클립 저장 위치도 함께)
- [ ] 호스팅 해서 클립 공유 시 자체적으로 추출한 클립이 아닌 파일 구분하도록 하기
- [ ] 개발과 배포 모드 분리
  - 개발 시에 사용하는 기능들(클립 id 확인, 로그 전송, 라벨링 등)은 배포 시 자동으로 비활성화 되도록
