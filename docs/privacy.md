# 개인정보 처리 안내 (초안)

> **초안입니다.** 서버 쪽 설정(접근 로그 IP 비활성, 로그·진단 90일 자동 삭제, 삭제 요청 처리)은 2026-09-25 에 구현해 서버에 배포했고 접근 로그에 IP 가 남지 않는 것까지 확인했지만, 오류 기록에 IP 가 남는지와 90일 자동 삭제의 실제 동작은 아직 관측하지 못했고 앱의 전송 기능(D10·D14)도 아직 없습니다. 이것들이 아래 내용대로 동작하는 것을 확인한 뒤에 확정·공개합니다. 확정 전에는 첫 실행 화면과 README에서 링크하지 않습니다. 구현과 이 문서가 어긋나면 구현을 문서에 맞추거나 문서를 고칩니다.

루미아 브리핑룸(이하 "이 프로그램")은 님블뉴런과 무관한 비공식 팬 제작 도구입니다. 핵심 기능(게임 검출·클립 생성·열람)은 인터넷 없이 내 PC 안에서만 동작하며, 아래의 데이터 전송은 **직접 켠 경우에만** 이루어집니다.

## 1. 기본 원칙

- 전송 기능은 **모두 꺼진 상태로 시작**하고, 첫 실행 화면이나 옵션에서 직접 켜야 합니다. 끄거나 켜지 않아도 기능 제한은 없습니다.
- **영상, 썸네일, 결과표 이미지, 화면 조각은 어떤 경우에도 전송하지 않습니다.**
- 닉네임, 팀원 정보, 파일 경로 원문, 스팀·게임 계정 정보는 전송하지 않습니다.

| 라벨 | 클립을 "교전 / 그 외"로 분류한 값, 검출 근거 수치, 녹화 해상도·게임 모드, 결과 화면의 최종 킬·어시스트 수, 내 캐릭터 이름(닉네임·팀원 정보는 제외), 직접 적은 라벨 메모 | 라벨 전송 |

## 3. 이용 목적

- 게임 검출기와 교전 분류 정확도 개선(여러 PC·해상도에서의 테스트 데이터)
- 오류 원인 파악과 지원되는 환경 확인
- 문의 처리(진단 정보의 접수 번호·표시용 ID 로 해당 데이터를 찾음)

이 외의 목적(광고, 이용자 추적, 판매)으로 쓰지 않으며 제3자에게 제공하지 않습니다.
