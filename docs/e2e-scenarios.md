# 화면 E2E 시나리오

> 브라우저(Chromium)로 앱을 실제로 눌러 보는 테스트의 목록이다. 실행·결과 읽기·고치는 법은
> [DEVELOPMENT.md "화면 E2E"](DEVELOPMENT.md). 시나리오는 `e2e/test_*.py` 에 있고, 이 문서는 **무엇을 확인하는지**와
> **옛 사람 체크리스트의 어느 항목을 대신하는지**를 적는다. 새 시나리오를 만들면 이 표에도 한 줄 더한다.
> 시나리오 이름은 `test_<영역><번호>_<확인하는 것>` (L=게임 목록, V=풀영상 화면, E=풀영상 편집, C=클립 탭, D=영상 파일 탭, P=보관 클립 보호, U=0.1.x 데이터 업그레이드·새 구조로 옮기기, F=첫 실행·사용 안내).

## 다음에 만들 시나리오 (우선순위 순)

시드가 더 필요한 것은 [plan-release-automation.md §3.2](plan-release-automation.md) 의 `edge` 세트를 먼저 만든다(`vod`·`legacy` 세트는 `world.add_vod`·`add_legacy_*` 로 만들었다).

1. **옵션**: 클립 보관 방식 기본값 `자동 보관`, 저장 폴더 화면(옮기기·되돌리기·같은 디스크 경고 — 가짜 환경 필요), 자동 정리 화면 문구, `?` 도움말 말풍선이 잘리지 않는지.
2. **자동 정리**: 한도를 낮춰 `삭제 예정` 배지·`삭제 예정만 보기`·확인 창, 고정 게임은 안 잡힘.
3. **가짜 환경이 필요한 것**(R2): 디스크 부족 배너·트레이 알림, 스팀 녹화 오류 배지(`edge` 세트), 감시 실패 배너·`계속하기`.
4. **게임 정보 수정**: 순위·TK/K/A·제목 고치기, 코발트의 승리/패배 선택.
