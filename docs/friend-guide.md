# 루미아 브리핑룸 — 설치하고 확인해 주기

이터널 리턴 게임에서 **교전 장면만 자동으로 잘라 주는** 프로그램입니다.
아직 테스트 중이라, 설치해서 한두 판 돌려 보고 아래 표만 채워 주시면 큰 도움이 됩니다.

문제가 생기면 글로 설명하지 않아도 됩니다 — **진단 파일 하나만 보내 주세요**(맨 아래).

---

## 0. 미리 알아 두실 것

- **게임을 건드리지 않습니다.** 게임 프로세스나 메모리, 네트워크에 손대지 않고,
  **스팀이 이미 저장해 둔 녹화 파일만 읽습니다.** 안티치트와 무관합니다.
- **아무것도 인터넷으로 보내지 않습니다.** 지금 버전에는 전송 기능 자체가 없습니다.
- 용량을 꽤 씁니다. 설치에 약 400MB, 클립은 게임마다 수백 MB씩 쌓입니다
  (옵션 → 자동 정리에서 기간·용량 상한을 켤 수 있습니다).

## 1. 준비 — 스팀 배경 녹화 켜기

이 프로그램은 **스팀이 녹화해 둔 파일**에서 장면을 잘라냅니다. 먼저 스팀에서 켜 주세요.

1. 스팀 → 설정 → **게임 녹화**
2. **백그라운드 녹화**를 켭니다
3. 녹화 저장 위치와 "녹화 시간"(버퍼)을 확인합니다 — **2시간 이상**을 권합니다.
   짧으면 게임이 끝나기 전에 앞부분이 지워져 클립을 못 만듭니다.
4. 이터널 리턴을 한 판 하고 나옵니다

## 2. 설치

1. 받은 `LumiaBriefingRoom-x.y.z-setup.exe` 를 실행합니다.
2. **파란 경고창이 뜹니다** — "Windows의 PC 보호". 서명 인증서를 사지 않아서 그렇습니다.
   → **추가 정보** → **실행** 을 누르면 진행됩니다.
3. 관리자 권한은 묻지 않습니다. 내 계정 폴더에만 설치됩니다.
4. 설치가 끝나면 실행됩니다. 작업표시줄 오른쪽 **트레이 아이콘**(`^` 안에 숨어 있을 수 있음)으로 상주합니다.

**첫 실행 화면**이 뜹니다. 녹화 폴더를 자동으로 찾았는지, 녹화 해상도를 지원하는지 보여 줍니다.
녹화 폴더를 못 찾았다고 나오면 **직접 고르기**를 눌러 `bg_1049590_…` 같은 이름의 폴더들이 들어 있는 `video` 폴더를 고르세요.
스팀에서 녹화 폴더를 바꾸지 않았다면 기본 위치는 `스팀 설치 폴더\userdata\숫자\gamerecordings\video` 입니다
(`gamerecordings` 를 골라도 자동으로 `video` 로 바로잡습니다).
나중에 바꾸고 싶으면 **⚙ 옵션 → 일반 → 스팀 녹화 폴더 → 바꾸기** 에서 다시 고를 수 있습니다.
확인하고 "시작하기"를 누르세요. (이 화면이 안 뜨면 트레이 아이콘 → "루미아 브리핑룸 열기")

그다음부터는 **켜 두기만 하면 됩니다.** 게임이 끝날 때마다 알아서 클립을 만듭니다
(게임 하나에 2~6분 걸립니다). 트레이 아이콘 → "루미아 브리핑룸 열기"로 결과를 봅니다.

## 3. 확인해 주실 것

아래를 채워서 보내 주세요. **모르면 비워 두셔도 됩니다.**

| 항목 | 적어 주실 것 |
|---|---|
| PC 사양 | CPU / 그래픽카드 / RAM |
| 게임 해상도 | 예: 2560x1440, 1920x1080, 3440x1440(울트라와이드) |
| 게임 화면 모드 | 전체 화면 / 테두리 없는 창 / 창 |
| 게임 UI 크기 설정 | 기본값인지, 바꿨는지 |
| 스팀 녹화 해상도 | 스팀 설정 → 게임 녹화에 있습니다 |
| **첫 클립이 만들어졌나요?** | 예 / 아니오 (아니면 몇 분 기다렸는지) |
| **클립이 재생되나요?** | 잘 나옴 / 검은 화면 / "재생용 영상을 만드는 중…"이 뜬 뒤 나옴 |
| 킬·데스 숫자(K/A)가 맞나요? | 맞음 / 틀림 / 안 보임 |
| 지역 이름이 맞나요? | 예: "항구", "병원" 이 제목에 맞게 나오는지 |
| 순위·캐릭터가 맞나요? | 게임 한 줄에 `#4 랭크 13/3/6` 처럼 나오는 부분 |
| **게임 중 렉이 느껴졌나요?** | 특히 게임이 끝난 직후 다음 판을 할 때 |
| Windows를 켤 때 자동 실행되나요? | 예 / 아니오 |
| 설치할 때 경고가 떴나요? | SmartScreen(파란 창) / 백신이 차단 / 없음 |
| 그 밖에 이상한 점 | 자유롭게 |

특히 궁금한 것:

- **16:9 가 아닌 모니터**(21:9 울트라와이드, 16:10)를 쓰신다면 꼭 알려 주세요.
  화면 위치 계산이 틀릴 가능성이 큽니다.
- **"재생용 영상을 만드는 중…"**이 뜨는지. 이건 그 PC에 HEVC 코덱이 없어서
  H.264 재생용 영상을 만드는 정상 동작입니다. 뜨는지 안 뜨는지가 알고 싶습니다.

## 4. 문제가 생기면 — 진단 파일 보내기

1. 트레이 아이콘 → **루미아 브리핑룸 열기**
2. 오른쪽 위 **⚙ 옵션** → **정보·진단** 탭
3. **진단 정보 zip 받기** 를 누르고, 저장된 파일을 보내 주세요.

이 파일에는 **로그·버전·녹화 해상도·설정**만 들어갑니다.
**닉네임과 경로 속 Windows 사용자 이름은 지워지고, 영상이나 화면 이미지는 들어가지 않습니다.**
보내기 전에 열어서 확인하셔도 됩니다(그냥 zip 입니다).

앱이 아예 안 뜨면 대신 이 폴더의 파일을 보내 주세요:
`%LOCALAPPDATA%\LumiaBriefingRoom\logs` (탐색기 주소창에 그대로 붙여넣기)

## 5. 지우고 싶으면

설정 → 앱 → "루미아 브리핑룸" → 제거. 또는 시작 메뉴의 "루미아 브리핑룸 제거".

- **만들어진 클립은 지워지지 않습니다** (기본 위치 `내 비디오\LumiaBriefingRoom`).
  필요 없으면 직접 지우세요.
- 설정과 로그를 지울지는 제거할 때 물어봅니다.

## 6. 자주 묻는 것

**Q. 게임이 렉 걸리지 않나요?**
분석은 낮은 우선순위로 돌게 해 두었지만, 게임 직후 2~6분 동안 CPU를 씁니다.
느껴지면 꼭 알려 주세요 — 그게 이번에 제일 궁금한 것 중 하나입니다.

**Q. 클립이 하나도 안 생겨요.**
① 스팀 배경 녹화가 켜져 있는지 ② 게임을 끝까지 하고 로비로 나왔는지
③ 트레이 메뉴에 "감시 중"에 체크가 있는지 확인해 주세요. 그래도 안 되면 진단 파일을 보내 주세요.

**Q. 클립이 검게 나와요(소리만 나옴).**
그 PC에 HEVC 코덱이 없어서입니다. 자동으로 재생용 영상(H.264)을 만들어 재생해야 정상인데,
그게 안 된 것이므로 **진단 파일을 꼭 보내 주세요.**

**Q. 백신이 잡아요.**
서명이 없는 프로그램이라 오탐일 수 있습니다. 차단된 화면을 캡처해서 알려 주세요.
